# P4MI Tangerang – Website Informasi & Layanan

Website Pos Pelayanan Perlindungan Pekerja Migran Indonesia (P4MI) Tangerang.  

---

## 🛠️ Teknologi yang Digunakan

- PHP >= 8.2
- Laravel 11
- MySQL / MariaDB
- Node.js & NPM
- Vite
- Tailwind CSS
- Chart.js
- Swiper.js
- Laravel Excel (maatwebsite/excel)

---

## 📦 Kebutuhan Sistem

Pastikan software berikut sudah terpasang:

- PHP >= 8.2
- Composer
- composer require maatwebsite/excel
- Node.js (LTS disarankan)
- NPM
- MySQL / MariaDB
- Web Server (Apache / Nginx / Laragon / XAMPP)
